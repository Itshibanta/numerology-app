# Le Nombre Héréditaire : L'Héritage de Votre Lignée

Issu de votre nom de famille, le nombre héréditaire reflète les forces, les fragilités et les réflexes transmis par votre lignée.

## Qu'est-ce que le nombre héréditaire ?

Le nombre héréditaire reflète l'héritage familial : des schémas transmis (forces, fragilités, réflexes) qui influencent votre fonctionnement. Il se calcule à partir de votre nom de famille de naissance.

## Comment calculer son nombre héréditaire

On additionne la valeur des lettres du nom de famille (table pythagoricienne), puis on réduit, sauf Nombre Maître (11, 22, 33, 44). Exemple : Dupont = 27 → 9.

## Pourquoi le nombre héréditaire est-il important ?

Il éclaire les schémas familiaux qui agissent en vous. Le connaître aide à distinguer ce qui vient de vous de ce qui vient de votre lignée, et à transformer les fragilités héritées.

## Questions fréquentes sur le nombre héréditaire

**Qu'est-ce que le nombre héréditaire ?** L'héritage de votre lignée, calculé à partir du nom de famille.

**Différence avec le nombre d'expression ?** L'expression vient du nom complet (talents) ; l'héréditaire vient du seul nom de famille (héritage transmis).

**Peut-on avoir un héréditaire maître ?** Oui, si le total du nom de famille donne 11, 22, 33 ou 44 avant réduction finale.
